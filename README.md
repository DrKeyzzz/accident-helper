# Accident Helper

A phone friendly guide that walks someone through a car insurance claim one task at a time: 9 stages, 24 tasks, copyable phone and email scripts, a "My info" page, a payment tracker, and backup and restore.

Everything a person types is saved only in their own phone's browser (localStorage). Nothing is sent anywhere, and no personal details are in this repo.

## Publish on GitHub Pages
1. Push this folder to a GitHub repo.
2. Repo Settings > Pages > Source: Deploy from a branch > main, / (root).
3. The site appears at https://<user>.github.io/<repo>/.
